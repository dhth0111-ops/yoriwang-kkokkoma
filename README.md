# 요리왕 꼬꼬마 V3.5 Dev Fix4

V3.4 Stable을 기반으로 정리한 개발판 전체 프로젝트입니다.

## 주요 기능
- 설정 화면 정상 표시
- 장보기 제품 사진 추가·변경·삭제·크게 보기
- 구매처 여러 곳과 구매 링크 저장
- 기본자료 저장·초기화
- 사진을 포함한 전체 JSON 백업·복원

## Fix4 수정 사항
- 레시피 목록 사진의 고정 높이와 `object-fit: cover` 제거
- 레시피 상세 사진과 등록 미리보기의 원본 비율 유지
- 휴대폰에서 편집해 올린 세로·가로·정사각형 사진을 추가로 자르지 않고 표시
- 장보기 썸네일도 잘리지 않도록 `contain` 방식 적용
- `index.html`, `app.js`, `style.css`, `manifest.json`, `service-worker.js` 버전을 Fix4로 통일
- 서비스 워커 캐시 이름을 Fix4로 갱신하고 이전 캐시 자동 삭제

## 새로 배포하는 방법
1. JSON 백업 파일을 별도로 보관합니다.
2. Dev 저장소의 기존 프로젝트 파일을 삭제하고 커밋합니다.
3. 이 ZIP의 내용 전체를 저장소 최상위에 업로드하고 다시 커밋합니다.
4. GitHub Pages 배포 완료 후 기존 설치 앱을 삭제하고 새로 설치합니다.
